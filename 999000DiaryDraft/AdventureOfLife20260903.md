Excel文档一旦修改就无法保存并生成多个临时文件，通常是因为冲突的进程阻止了Excel的正常覆盖保存机制。Excel在保存时，会先创建一个隐藏的临时文件，保存成功后再删除原文件并将临时文件重命名。如果这个过程被卡住，就会留下一堆乱码文件（如 DF12A3.tmp 或没有后缀的文件）。请尝试以下排查与解决方法：
1. 关闭第三方软件的干扰关闭杀毒软件：部分安全软件（如360、火绒、Windows Defender）的实时扫描功能可能会误将Excel的保存动作锁定。尝试暂时关闭杀毒软件再试。关闭网盘自动同步：如果你的文件保存在 OneDrive、坚果云、百度网盘等同步盘中，同步软件在检测到文件修改时会立即进行同步，从而锁定了文件。保存前请先暂停同步软件。
2. 检查文件权限与路径检查文件名和路径：确保文件路径不要太长，且文件夹名称中没有特殊字符。尝试“另存为”：不要直接按 Ctrl+S，点击 文件 -> 另存为，将文件换个名字保存到桌面（本地路径），看是否正常。
3. 禁用Excel加载项有些第三方插件（如PDF转换工具、企业办公插件）会导致保存冲突：打开Excel，点击左上角的 文件 -> 选项。选择 加载项。在底部“管理”下拉菜单中选择 COM加载项，点击 转到。取消勾选所有加载项，点击确定，然后重启Excel。
4. 修复Office办公软件如果上述方法无效，可能是Excel组件损坏：打开电脑的 控制面板 -> 程序和功能。找到你的 Microsoft Office 或 Microsoft 365。右键点击它，选择 更改，然后选择 快速修复（或联机修复）。
