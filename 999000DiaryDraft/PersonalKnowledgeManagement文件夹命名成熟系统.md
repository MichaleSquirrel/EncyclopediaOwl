# PersonalKnowledgeManagement文件夹命名成熟系统

## 1.类似的文件夹命名系统或规范

「6 位数字前缀 + 语义名 + 预留空号」的体系，在多个成熟系统中有对应物：

| 系统 | 相似点 |
|------------|--------|
| **Johnny Decimal**（个人文件组织法） | 最接近的同类：编号强制排序、分类-层级结构、"永不重新编号"、为插入新条目留空号。区别是它用两级短编号（如 `15.02`），本体系用 6 位定长 |
| **杜威十进制分类法（DDC）** | 图书馆知识分类，纯数字层级编码（000 计算机类、900 史地类），900000 个人百科段和它的"总类"思路同源 |
| **中图法 / 美国国会图书馆分类（LCC）** | 字母+数字层级分类，学术领域常用 |
| **Zettelkasten（卢曼卡片盒）** | 数字编号表达笔记层级与父子关系（如 `21/3d7a14`），Obsidian 用户常借鉴 |
| **PARA / BASB** | 理念类似（Projects-Areas-Resources-Archives 分区），但无编号前缀 |
| **ICD、HS Code、UNSPSC** | 更宏观的层级数字编码系统（疾病/海关/采购分类），思路同构 |

## 2.本体系的特色

相比上述成熟系统，本体系的特色：

- **数字段位含义自定义**：6xx=Java、63x=项目源码、937xxx=工作项目
- **空号间隔**：如 110014→110018，允许不破坏排序地插入新目录

这点与图书馆分类"预留空位"和 Johnny Decimal 的稳定性原则一致，属于经过验证的好实践。
