## 4.如何学习AI

如何学习AI？
AI 学习路径建议：

基础：Python 编程、线性代数、概率统计、微积分
机器学习：吴恩达 ML 课程、scikit-learn 实践
深度学习：吴恩达 DL 专项课、PyTorch/TensorFlow 框架
进阶方向：NLP（Transformer/LLM）、CV（CNN/ViT）、强化学习
实战：Kaggle 比赛、复现经典论文、做个人项目
前沿：阅读 NeurIPS/ICML/ACL 论文，关注 Hugging Face、arXiv
推荐资源：Coursera、fast.ai、李宏毅课程、《深度学习》（花书）、动手学深度学习（d2l.ai）。

如何学习使用AI
学习使用 AI（作为工具）的建议：

入门：直接用 ChatGPT/Claude/文心一言等，练习提问技巧（Prompt）
Prompt 工程：学习清晰描述任务、给示例、分步骤、指定角色
场景实践：写文案、翻译、总结、写代码、数据分析、做PPT
进阶工具：Copilot（编程）、Midjourney（画图）、NotebookLM（文档分析）、OpenAI GPTs（定制助手）
API 开发：调用 OpenAI/通义/智谱 API，搭建自己的 AI 应用
工作流自动化：用 Dify/Coze/LangChain 构建 Agent 和工作流
持续关注：公众号「机器之心」「量子位」、B 站教程、小红书 AI 案例
核心心法：边用边学，遇到任何任务先问自己"AI 能帮我做吗？"。
