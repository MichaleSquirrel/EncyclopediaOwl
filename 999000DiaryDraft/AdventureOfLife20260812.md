## 4.word文档所有表格添加边框

如果你有几十个甚至上百个表格，使用宏可以瞬间为它们全部加上边框：按下键盘上的 Alt + F11 键，打开 VBA 编辑器。点击顶部菜单栏的 插入 -> 模块。把下面的代码复制并粘贴到空白的代码窗口中：vbaSub AddBordersToAllTables()
Dim tbl As Table
For Each tbl In ActiveDocument.Tables
tbl.Borders.Enable = True ' 启用所有边框
Next tbl
MsgBox "已成功为所有表格添加边框！"
End Sub
Use code with caution.把光标放在代码中间，按下键盘上的 F5 键运行代码即可。运行完毕后提示成功，所有表格就都有边框了。
